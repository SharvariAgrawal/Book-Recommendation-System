# 📚  Book Recommendation System

This is a academic project. 
This is a **hybrid book recommendation engine** built using machine learning techniques such as **Content-Based Filtering**, **Collaborative Filtering**, **K-Nearest Neighbors (KNN)**, and **Singular Value Decomposition (SVD)**. The model is evaluated using **Precision** and **Recall** metrics, and a simple UI is built using **Streamlit**.

---

## 🎯 Objective

To recommend books tailored to user preferences by combining both item metadata (content-based) and user interaction data (collaborative-based), while offering a simple and intuitive interface for demonstration.

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Frontend:** Streamlit  
- **Libraries:**  
  - Pandas, NumPy  
  - Scikit-learn  
  - Surprise (for SVD and KNN)  
  - Streamlit (for UI)

---

## ✨ Features

- 🔍 **Content-Based Filtering** using TF-IDF and Cosine Similarity  
- 🤝 **Collaborative Filtering** using KNN and Matrix Factorization (SVD)  
- 🧠 **Hybrid Model** that combines both techniques  
- 📈 **Evaluation Metrics**: Precision@K and Recall@K  
- 🖥️ **Interactive Web Interface** using Streamlit
